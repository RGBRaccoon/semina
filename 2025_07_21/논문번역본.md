초록
고전적인 머신러닝은 훈련 세트와 테스트 세트가 동일한 분포에서 나온다고 가정합니다. 따라서 레이블된 훈련 데이터로부터 학습된 모델은 테스트 데이터에서도 잘 작동할 것으로 예상됩니다. 그러나 훈련 및 테스트 데이터가 서로 다른 분포를 보이는 실제 응용 프로그램에서는 이러한 가정이 항상 유지되지 않을 수 있습니다. 이는 다양한 요인, 예를 들어 훈련 세트와 테스트 세트를 다른 소스에서 수집하거나, 시간이 지남에 따라 데이터가 변경되어 오래된 훈련 세트를 가지게 되는 경우 때문입니다.

이 경우, 도메인 분포 간에 불일치가 발생하며, 훈련된 모델을 새 데이터셋에 단순히 적용하면 성능 저하를 초래할 수 있습니다. **도메인 적응(Domain adaptation)**은 도메인 간의 불일치를 조정하여 훈련된 모델이 관심 도메인으로 일반화될 수 있도록 함으로써 이러한 유형의 문제를 해결하는 것을 목표로 하는 머신러닝 내의 하위 분야입니다. 이 논문은 레이블이 소스 도메인에서만 사용 가능한 **비지도 도메인 적응(unsupervised domain adaptation)**에 초점을 맞춥니다. 다양한 관점에서 도메인 적응의 분류를 다루고, 도메인 적응 문제를 해결하기 위한 성공적인 얕은(shallow) 및 깊은(deep) 도메인 적응 접근 방식을 제시합니다.

키워드: 머신러닝 · 전이 학습 · 도메인 적응 · 분류 · 위험 최소화

1 서론
전통적인 머신러닝은 훈련 샘플 세트에서 모델을 학습하여 보이지 않는 테스트 데이터에 대한 위험이 최소화된 목적 함수를 찾는 것을 목표로 합니다. 그러나 이러한 일반화된 모델을 훈련하기 위해서는 훈련 및 테스트 데이터가 모두 동일한 분포에서 추출되었고 유사한 결합 확률 분포를 공유한다고 가정합니다. 이 제약은 훈련 및 테스트 세트가 다른 특징 공간이나 분포에서 유래할 수 있으므로 실제 응용 프로그램에서는 쉽게 위반될 수 있습니다.

훈련 데이터와 동일한 속성, 차원 및 분포를 가진 새로운 인스턴스를 수집하는 어려움은 다양한 이유로 발생할 수 있습니다. 예를 들어, 도메인의 통계적 속성이 시간 경과에 따라 진화하거나, 새로운 샘플이 다른 소스에서 수집되어 **도메인 변화(domain shift)**를 야기할 수 있습니다. 게다가, 가능하다면 힘들고 시간이 많이 소요되는 새로운 레이블된 데이터셋을 만드는 대신, 관련 공개적으로 사용 가능한 어노테이션된 데이터를 훈련 데이터셋으로 활용하는 것이 선호됩니다. 그러나 훈련 데이터가 테스트 데이터 분포를 정확하게 반영하지 못하면, 훈련된 모델은 테스트 데이터에 적용될 때 성능 저하를 경험할 가능성이 높습니다.

위 문제를 해결하기 위해 연구자들은 머신러닝에서 도메인 적응이라는 새로운 연구 분야를 제안했습니다. 이 설정에서 훈련 및 테스트 세트는 각각 **소스 도메인(source domain)**과 **타겟 도메인(target domain)**으로 불립니다. 도메인 적응은 일반적으로 도메인 분포 간의 차이를 최소화하여 소스 레이블된 데이터로부터 타겟 도메인으로 일반화될 수 있는 모델을 학습하는 것을 목표로 합니다.

도메인 적응은 **전이 학습(transfer learning)**의 특별한 경우입니다 [1]. 이 두 가지 밀접하게 관련된 문제 설정은 머신러닝의 하위 분야로, 어노테이션된 데이터가 불충분하거나 부족한 타겟 모델의 성능을 충분한 레이블된 데이터를 가진 다른 관련 도메인의 지식을 활용하여 향상시키는 것을 목표로 합니다.

우리는 먼저 전이 학습과 그 범주를 간략하게 검토하고, 이어서 전이 학습 및 도메인 적응과 관련된 기존 연구들을 다룰 것입니다. 전이 학습은 소스와 타겟 간에 태스크 및/또는 도메인이 변경될 수 있는 머신러닝 문제의 한 종류를 의미하는 반면, 도메인 적응에서는 도메인만 다르고 태스크는 동일하게 유지됩니다. 전이 학습에서 도메인은 특징 공간과 주변 확률 분포로 구성되며, 태스크는 레이블 공간과 목적 예측 함수를 포함합니다. 따라서 도메인과 태스크의 다양한 가능한 시나리오가 서로 다른 전이 학습 설정을 생성합니다. Pan et al. [1]은 전이 학습을 세 가지 주요 범주로 분류합니다: 귀납적(inductive) 전이 학습, 변환적(transductive) 전이 학습, 그리고 비지도(unsupervised) 전이 학습.

귀납적 전이 학습은 소스와 타겟 태스크가 다른 상황을 의미하며, 도메인이 다르든 다르지 않든 상관없습니다. 이 설정에서는 소스 도메인에 어노테이션된 데이터가 포함될 수도 있고 포함되지 않을 수도 있지만, 타겟 도메인에는 훈련 데이터로 사용될 소수의 레이블된 데이터가 필요합니다.

변환적 전이 학습에서는 도메인은 다르지만 태스크는 변경되지 않으며, 레이블된 데이터는 소스 도메인에서만 사용할 수 있습니다. 그러나 타겟 도메인의 레이블 없는 데이터 중 일부는 훈련 시에 주변 확률 분포를 얻기 위해 필요합니다.

마지막으로 비지도 전이 학습은 귀납적 전이 학습과 유사하게 태스크가 다른 시나리오를 의미합니다. 하지만 소스와 타겟 도메인 모두 레이블 없는 데이터를 포함합니다.

전이 학습 및 도메인 적응과 유사하게, **준지도 분류(Semi-supervised classification)**는 레이블된 데이터가 불충분한 문제를 다룹니다. 이 문제 설정은 풍부한 레이블 없는 샘플과 소량의 어노테이션된 샘플을 활용하여 모델을 훈련시킵니다. 이 접근 방식에서는 레이블된 데이터와 레이블 없는 데이터 샘플 모두 동일한 분포에서 추출되었다고 가정합니다. 반면, 전이 학습과 도메인 적응은 이 가정을 완화하여 도메인이 서로 다른 분포에서 나올 수 있도록 합니다 [2], [3].

다중 작업 학습(Multi-task learning) [4]은 여러 관련 작업을 동시에 훈련함으로써 일반화 성능을 향상시키는 것을 목표로 하는 또 다른 관련 작업입니다. 관련 작업은 공통 정보를 활용한다고 가정하므로, 다중 작업 학습은 데이터의 기본 구조를 학습하고 모든 작업에 걸쳐 공통 표현을 공유하는 경향이 있습니다. 전이 학습과 다중 작업 학습 사이에는 몇 가지 유사점과 차이점이 있습니다. 이 두 학습 기법은 학습자의 성능을 향상시키기 위해 전이된 지식을 활용하기 위해 매개변수 공유(parameter sharing) 및 **특징 변환(feature transformation)**과 같은 유사한 절차를 사용합니다. 그러나 전이 학습은 먼저 소스 도메인에서 모델을 훈련한 다음 관련 지식을 타겟 학습자에게 전이하여 타겟 학습자의 성능을 향상시키는 것을 목표로 합니다. 반면 다중 작업 학습은 여러 관련 작업을 함께 훈련하여 이들의 성능을 향상시키는 것을 목표로 합니다.

유사하게, **다중 뷰 학습(multi-view learning)**은 오디오+비디오, 이미지+텍스트, 텍스트+텍스트 등과 같은 다중 뷰 데이터 또는 여러 개의 독특한 특징 세트로부터 학습하는 것을 목표로 합니다. 예를 들어, 웹 페이지는 페이지 및 하이퍼링크 내용으로 설명될 수 있는데, 이는 두 가지 다른 텍스트 소스로 데이터를 설명하는 예시입니다. 이러한 유형의 학습 뒤에 있는 직관은 다중 뷰 데이터가 보완적인 정보를 포함하며, 모델이 일반화 성능을 향상시키기 위해 더 포괄적이고 압축된 표현을 학습할 수 있다는 것입니다. 다중 뷰 학습의 몇 가지 실제 응용 예시는 비디오 분석 [5], [6], 화자 인식 [7], [8], 자연어 처리 [9], [10], [11], 추천 시스템 [12], [13] 등입니다. 정준 상관 분석(Canonical correlation analysis, CCA) [14]과 코트레이닝(co-training) [15]은 다중 뷰 학습 개념에서 소개된 최초의 대표적인 기법으로, 전이 학습에서도 사용됩니다 [16].

도메인 일반화(Domain generalization) [17] 또한 여러 어노테이션된 소스 도메인에서 모델을 훈련하여 보이지 않는 타겟 도메인으로 일반화될 수 있도록 하는 경향이 있습니다. 도메인 일반화에서는 훈련 시 타겟 샘플을 사용할 수 없습니다. 그러나 도메인 적응은 도메인 간의 변화를 조정하기 위해 훈련 중에 타겟 데이터를 필요로 합니다.

3 도메인 적응의 분류
기존의 도메인 적응은 특징 및 레이블 공간이 변경되지 않는다고 가정하지만, 확률 분포는 도메인 간에 다를 수 있습니다. 그러나 동일한 레이블 공간을 가진 소스 및 타겟 도메인을 찾는 것은 일반적으로 어렵거나 심지어 불가능합니다. 소스 및 타겟 레이블 공간이 동일하지 않을 때, 전체 소스 및 타겟 분포를 일치시키는 것은 타겟 클래스에 존재하지 않는 소스 클래스에 속하는 데이터의 특징을 포함하는 표현 공간을 생성할 것입니다. 타겟 도메인은 이러한 클래스를 **이상치 클래스(outlier classes)**로 간주하며, 이들의 지식을 타겟 도메인으로 확장하면 **부정적 전이(negative transfer)**를 유발하여 모델 성능에 심각한 해를 끼칠 것입니다. 따라서 주변 분포 불일치 외에도 레이블 공간이 도메인 간에 다른 다양한 시나리오를 고려해야 합니다.

서로 다른 주변 분포와 서로 다른 레이블 공간은 각각 **도메인 갭(domain gap)**과 **범주 갭(category gap)**이라고 불립니다. 범주 갭을 기반으로 도메인 적응은 네 가지 주요 범주로 나눌 수 있습니다: 폐쇄 집합(closed set), 개방 집합(open set), 부분(partial), 그리고 전역(universal) 도메인 적응입니다.

**폐쇄 집합 도메인 적응(Closed set domain adaptation)**은 소스 및 타겟 도메인이 동일한 클래스를 공유하지만 도메인 간에 여전히 도메인 갭이 존재하는 상황을 의미합니다. 전통적인 도메인 적응은 이 범주에 속합니다.

**개방 집합 도메인 적응(Open set domain adaptation)**에서는 관련 도메인이 공통 레이블 세트에서 일부 레이블을 공유하고 또한 사적인 레이블을 가질 수 있습니다 [20]. Saito et al. [21]은 소스 사적 클래스의 데이터가 제거된 새로운 개방 집합 도메인 적응을 소개했습니다. 수정된 개방 집합에서 소스 레이블 세트는 타겟 레이블 세트의 부분 집합으로 간주됩니다. 개방 집합 도메인 적응은 각 소스 도메인이 타겟 클래스의 부분 집합을 포함하는 여러 소스 도메인이 있을 때 적합합니다. 도메인 적응 기술은 공유 클래스에 포함된 모든 소스 도메인 정보를 활용하여 타겟 도메인에서 모델의 성능을 향상시키는 것을 목표로 합니다.

개방 집합과 대조적으로, **부분 도메인 적응(partial domain adaptation)**은 타겟 레이블 세트가 소스 레이블 세트의 부분 집합인 상황을 의미합니다 [22], [23]. 이 설정에서 사용 가능한 소스 도메인은 풍부한 수의 클래스로 구성된 일반적인 도메인으로 간주될 수 있으며, 타겟은 더 적은 클래스를 가진 소스 레이블 세트의 부분 집합일 뿐입니다.

전역 도메인 적응(Universal domain adaptation, UDA) [24]은 위 시나리오들을 일반화합니다. 소스 및 타겟 레이블 세트에 대한 사전 지식을 요구하는 위 설정들과 달리, 전역 도메인 적응은 어떤 사전 지식에도 제한되지 않습니다. 이 설정에서는 소스 및 타겟 도메인이 공통 레이블 세트를 공유할 수 있으며, 각 도메인은 사적인 레이블 세트 또는 이상치 클래스를 가질 수 있습니다. 전역 도메인 적응은 먼저 도메인 간의 공유 레이블 공간을 찾은 다음, 개방 집합 및 부분 도메인 적응과 유사하게 공통 레이블 세트에서 데이터 분포를 조정합니다. 궁극적으로, 분류기는 매칭된 소스 레이블된 데이터에 대해 훈련되어 레이블 없는 타겟 데이터에 안전하게 적용될 것입니다. 테스트 단계에서는 개방 집합 및 전역 도메인 적응 모두에서 훈련된 분류기가 공유 레이블 공간에 속하는 타겟 샘플에 정확한 레이블을 할당하고, 이상치 클래스의 샘플을 알 수 없음으로 표시할 것으로 예상됩니다.

이 개요는 **폐쇄 집합 비지도 도메인 적응(closed set unsupervised domain adaptation)**에 초점을 맞춥니다. 이러한 유형의 도메인 적응은 레이블된 소스 데이터와 레이블 없는 타겟 데이터를 활용하여 도메인 간에 변화가 있을 때 타겟 도메인에서 잘 작동할 수 있는 목적 예측 함수를 학습하는 것을 목표로 합니다. 도메인의 정의(섹션 2 참조)에 따라, 입력 공간, 출력 공간 또는 확률 밀도 함수 중 적어도 하나가 도메인 간에 변경되면 두 도메인은 다를 수 있습니다. 폐쇄 집합 도메인 적응은 특징 및 레이블 공간이 도메인 간에 동일한 반면, 결합 확률 분포는 다를 수 있는 상황을 고려합니다. 도메인 변화는 주로 세 가지 클래스로 분류될 수 있습니다: 사전 변화(prior shift), 공변량 변화(covariate shift), 그리고 개념 변화(concept shift).

4 접근 방식
기존의 도메인 적응 접근 방식은 크게 얕은(shallow) 아키텍처와 깊은(deep) 아키텍처를 가진 방법으로 분류할 수 있습니다.

얕은 도메인 적응 접근 방식 [25], [26], [27], [28]은 주로 인스턴스 기반(instance-based) 및 특징 기반(feature-based) 기술을 활용하여 도메인 분포를 조정합니다. 분포를 조정하는 한 가지 방법은 도메인 간의 거리를 최소화하는 것입니다. 도메인 적응에서 가장 많이 사용되는 거리 측정은 최대 평균 불일치(Maximum Mean Discrepancy, MMD) [29], 바서슈타인 거리(Wasserstein metric), 상관 정렬(correlation alignment, CORAL) [30], 쿨백-라이블러(Kullback-Leibler, KL) 발산 [31], 대조 도메인 불일치(contrastive domain discrepancy, CDD) [32]입니다.

반면, 깊은 도메인 적응 접근 방식 [33], [34], [35], [36]은 신경망을 활용합니다. 이러한 접근 방식은 일반적으로 합성곱(convolutional), 오토인코더(autoencoder), 또는 적대적(adversarial) 기반 네트워크를 사용하여 도메인 갭을 줄입니다. 이 범주의 일부 접근 방식은 소스 데이터용 네트워크 하나와 타겟 데이터용 네트워크 하나를 사용하여 두 네트워크의 하나 이상의 레이어에서 거리 측정법을 활용하여 해당 레이어의 특징 표현 간 불일치를 측정할 수도 있습니다.

4.2 특징 기반 적응
특징 기반 적응 접근 방식은 도메인 전반에 걸쳐 불변하는 특징 표현을 추출하는 변환을 학습하여 소스 데이터를 타겟 데이터에 매핑하는 것을 목표로 합니다. 이들은 일반적으로 원래 특징을 새로운 특징 공간으로 변환하여 새로운 특징 표현을 생성한 다음, 원래 데이터의 기본 구조를 보존하면서 최적화 절차에서 새로운 표현 공간의 도메인 간 갭을 최소화합니다. 부분 공간 기반(subspace-based), 변환 기반(transformation-based), **재구성 기반(reconstruction-based)**은 주요 특징 기반 적응 방법 중 일부입니다. 아래에서 각 범주와 관련된 접근 방식에 대해 자세히 설명합니다.

4.2.1 부분 공간 기반
부분 공간 기반 적응은 도메인 간에 공유되는 공통 중간 표현을 발견하는 것을 목표로 합니다. 소스 및 타겟 데이터의 저차원 표현으로부터 이 표현을 구성하기 위한 많은 기술이 제안되었습니다. 이 범주의 대부분의 적응 접근 방식은 먼저 각 도메인에 대한 선형 부분 공간 형태의 원래 데이터의 저차원 표현을 생성한 다음, 부분 공간 간의 불일치를 줄여 중간 표현을 구성합니다.

주성분 분석(PCA)과 같은 차원 축소 기술을 사용하여 저차원 그래스만(Grassmann) 다양체에서 각 도메인에 대해 두 점(각 도메인에 하나씩)으로 부분 공간을 구성할 수 있습니다. 그래스만 다양체에서의 점들 간의 거리는 다양한 방법을 적용하여 줄일 수 있는 도메인 변화를 나타냅니다. Goplan et al. [26]은 **샘플링 측지 흐름(Sampling Geodesic Flow, SGF)**을 제안했는데, 이는 먼저 그래스만 다양체에서 소스 및 타겟 점 사이의 측지 경로를 찾은 다음, 이 경로를 따라 소스 및 타겟 점을 포함하는 일련의 점, 즉 부분 공간을 샘플링합니다. 다음 단계에서 양쪽 도메인의 데이터는 측지 경로를 따라 모든 샘플링된 부분 공간에 투영되고 연결되어 고차원 벡터를 생성합니다. 마지막으로, 식별 분류기(discriminative classifier)는 소스 투영된 데이터로부터 학습하여 레이블 없는 샘플을 분류할 수 있습니다. 측지 경로에서 더 많은 점을 샘플링하면 소스 부분 공간을 타겟 부분 공간에 더 정확하게 매핑하는 데 도움이 됩니다. 그러나 더 많은 부분 공간을 샘플링하면 특징 벡터의 차원이 확장되어 이 기술은 계산 비용이 많이 듭니다.

측지 흐름 커널(Geodesic Flow Kernel, GFK) [45]은 SGF를 확장하고 개선하기 위해 제안되었습니다. GFK는 도메인 간의 변화를 다루는 커널 기반 도메인 적응 방법입니다. 이는 저차원 다양체 공간에서 도메인 간의 측지선을 찾기 위해 무한한 수의 부분 공간을 통합하여 소스에서 타겟 도메인으로의 전환의 부드러움을 표현하는 것을 목표로 합니다. Fernando et al. [46]은 그래스만 다양체에서 소스 점을 타겟 점으로 직접 투영하는 선형 매핑 함수를 학습하여 도메인 간의 불일치를 직접 줄이는 부분 공간 정렬(subspace alignment, SA) 기술을 제안했습니다. 투영 행렬 M은 버그만 행렬(Bergman matrix)의 발산(divergence)을 최소화함으로써 학습될 수 있습니다:

4.2.2 변환 기반
**특징 변환(Feature transformation)**은 원래 데이터의 기본 구조와 특성을 보존하면서 주변 및 조건부 분포 간의 불일치를 최소화하기 위해 원래 특징을 새로운 특징 표현으로 변환합니다. 도메인 불일치를 줄이기 위해서는 최대 평균 불일치(MMD), 쿨백-라이블러 발산(KL-divergence), 또는 **브레그만 발산(Bregman Divergence)**과 같은 일부 측정 기준이 필요합니다.

전이 구성 요소 적응(Transfer component adaptation, TCA) [27]은 RKHS에서 최대 평균 불일치(MMD) 기준을 사용하여 소스 및 타겟 도메인 간의 주변 분포를 최소화하는 도메인 불변 특징 변환을 학습하기 위해 제안되었습니다. 도메인 불변 특징을 찾은 후, 최종 타겟 분류기를 훈련하기 위해 어떤 고전적인 머신러닝 기술도 활용할 수 있습니다.

결합 도메인 적응(Joint domain adaptation, JDA) [48]은 도메인 간의 주변 및 조건부 분포를 동시에 일치시킴으로써 TCA를 확장합니다. JDA는 PCA를 차원 축소 기술로 활용하여 더 견고한 특징을 추출합니다. 저차원 특징은 MMD를 사용하여 주변 분포 간의 차이를 최소화하는 고차원 특징 공간에 임베드될 수 있습니다. 조건부 분포를 정렬하려면 두 도메인 모두에 레이블된 데이터가 필요합니다. 타겟 도메인에서 레이블을 사용할 수 없는 경우, 레이블된 소스 데이터에서 훈련된 분류기로 추정할 수 있는 **의사 레이블(pseudo labels)**을 사용할 수 있습니다. 의사 레이블을 얻은 후, 모델은 MMD를 수정하여 조건부 분포 간의 거리를 최소화합니다. 위 모든 단계는 도메인 전반에 걸쳐 주변 및 조건부 분포를 모두 정렬하는 최상의 매핑 함수를 찾기 위해 공동으로 반복적으로 수행됩니다. 최종 타겟 분류기는 알고리즘에 의해 발견된 도메인 불변 특징에 대해 훈련될 수 있습니다.

4.3 깊은 도메인 적응
최근 몇 년 동안, **깊은 신경망(deep neural networks)**은 표현 학습에 널리 사용되어 왔으며 이미지 분류 [50], 감성 분석 [51], 음성 인식 [52], [53], 객체 탐지 [54], [55], 객체 인식 [56], [57]과 같은 많은 머신러닝 작업에서 놀라운 결과를 달성했습니다. 깊은 신경망은 데이터의 일반화된 특징 표현을 추출하는 데 매우 강력한 기술입니다. 그러나 훈련을 위해서는 풍부한 레이블된 데이터가 필요하며, 많은 양의 데이터에 어노테이션을 다는 것은 힘들고 비용이 많이 들며 때로는 불가능합니다. 게다가, 신경망은 소스 및 타겟 도메인 모두 동일한 분포에서 샘플링된다고 가정하며, 도메인 변화는 성능을 크게 저하시킬 수 있습니다.

따라서 적응 기술과 함께 깊은 네트워크 속성을 배치함으로써 모델의 성능을 향상시키면서 충분한 레이블된 데이터 부족을 해결하기 위해 **깊은 도메인 적응(deep domain adaptation)**이 제안되었습니다. 깊은 네트워크 적응 기술은 주로 불일치 기반(discrepancy-based), 재구성 기반(reconstruction-based), 그리고 적대적 기반(adversarial-based) 적응으로 분류됩니다.
4.3.1 불일치 기반(Discrepancy-based)
Long et al. [33]은 도메인 적응 설정에서 깊은 신경망을 활용하여 도메인 간에 **전이 가능한 특징(transferable features)**을 학습하는 **깊은 적응 네트워크(Deep Adaptation Network, DAN)**를 처음으로 제안했습니다. DAN은 주변 분포 사이에 변화가 있는 반면 조건부 분포는 변하지 않는다고 가정합니다. 따라서 DAN은 작업별 표현(task-specific representations)을 위한 다중 적응 계층을 추가하여 도메인 간의 주변 분포를 일치시키는 경향이 있습니다. 적응 계층은 RKHS에 모든 작업별 표현을 임베드하고 주변 분포 간의 변화를 조정하기 위해 **다중 커널 MMD(Multiple Kernel Variant of MMD, MK-MMD)**를 활용합니다. DAN은 주변 분포만 조정하고 도메인 간의 조건부 분포 불일치는 고려하지 않습니다.

깊은 전이 네트워크(Deep Transfer Network, DTN) [58]는 주변 및 조건부 분포를 동시에 일치시키기 위해 제안되었습니다. DTN은 MMD 기반 분포 매칭 기술이며 두 가지 유형의 계층으로 구성됩니다. **공유 특징 추출 계층(shared feature extraction layer)**은 도메인 간의 주변 분포를 조정하기 위해 부분 공간을 학습하는 반면, **구분 계층(discrimination layer)**은 분류기 변환(classifier transduction)을 사용하여 조건부 분포를 일치시킵니다. 조건부 분포의 차이를 줄이기 위해 소스 레이블과 타겟 의사 레이블(pseudo labels)을 사용하여 데이터 포인트를 다른 클래스에 대해 다른 초평면(hyperplanes)에 투영합니다. 조건부 분포를 조정하기 위해 데이터 포인트를 먼저 소스 레이블과 타겟 의사 레이블을 사용하여 다른 초평면에 투영한 다음, 조건부 MMD 기반 목적 함수를 측정하고 최소화하여 조건부 분포 간의 불일치를 줄입니다.

4.3.2 재구성 기반(Reconstruction-based)
깊은 적응 네트워크의 또 다른 범주는 **오토인코더(autoencoder)**를 활용하여 재구성 오류를 최소화하고 도메인 간에 불변하고 전이 가능한 표현을 학습함으로써 도메인 간의 불일치를 조정합니다. 도메인 적응에서 오토인코더를 사용하는 목적은 한 도메인(소스)의 샘플을 기반으로 인코더의 매개변수를 학습하고, 다른 도메인(타겟)의 샘플을 재구성하도록 https://www.google.com/search?q=%EB%94%94%EC%BD%94%EB%8D%94를 적응시키는 것입니다.

Glorot et al. [34]은 소스 및 타겟 도메인 데이터를 모두 표현하기 위한 고수준 표현을 추출하기 위해 스택형 오토인코더(Stacked Auto Encoders, SDA) [75]를 기반으로 하는 깊은 도메인 적응 네트워크를 제안했습니다. 제안된 모델은 레이블 없는 데이터를 가진 다양한 도메인과 하나의 소스 레이블된 데이터에 접근할 수 있다고 가정합니다. 첫 번째 단계에서 고수준 특징 추출은 모든 사용 가능한 도메인에서 비지도 방식으로 학습함으로써 얻을 수 있습니다. 첫 번째 단계에서 모델은 재구성 오류를 최소화함으로써 모든 도메인의 데이터로부터 고수준 표현을 얻습니다. 다음으로, 선형 SVM과 같은 선형 분류기는 제곱 힌지 손실(squared hinge loss)을 최소화함으로써 소스 레이블된 데이터의 추출된 특징에 대해 훈련됩니다. 마지막으로, 이 분류기는 타겟 도메인에서 사용될 수 있습니다. 이 모델은 놀라운 결과를 보여주지만, SDA를 사용하면 특히 고차원 특징을 가질 때 계산 비용이 많이 들고 확장성이 떨어집니다.

마지널라이즈드 SDA(Marginalized SDA, mSDA) [77]는 SDA의 작업을 확장하고 그 한계를 해결하기 위해 제안되었습니다. mSDA는 선형 잡음 제거기(linear denoisers)로 잡음을 주변화하여 모델이 확률적 경사 하강법(stochastic gradient descent, SGD) [76]을 사용하지 않고 닫힌 형태 해(closed-form solution)로 매개변수를 학습하도록 유도합니다.

Ghifary et al. [73]은 객체 인식에서 비지도 도메인 적응을 위해 인코더-https://www.google.com/search?q=%EB%94%94%EC%BD%94%EB%8D%94 네트워크를 사용하는 **깊은 재구성-분류 네트워크(Deep Reconstruction-Classification Network, DRCN)**를 제안했습니다. DRCN은 소스 레이블을 예측하는 표준 합성곱 네트워크(인코더)와 타겟 샘플을 재구성하는 역합성곱 네트워크(deconvolutional networks) 74로 구성됩니다. 이 모델은 지도 학습 및 비지도 학습 전략을 공동으로 활용하여 소스 레이블을 예측하는 인코더 매개변수와 타겟 데이터를 재구성하는 https://www.google.com/search?q=%EB%94%94%EC%BD%94%EB%8D%94 매개변수를 학습합니다. 인코더 매개변수는 레이블 예측 및 재구성 작업 모두에 걸쳐 공유되는 반면, https://www.google.com/search?q=%EB%94%94%EC%BD%94%EB%8D%94 매개변수는 재구성 작업에만 비공개입니다.

4.3.3 적대적 기반(Adversarial-based)
강력한 도메인 불변 특징 추출기로서 **적대적 학습(adversarial learning)**의 성공은 많은 연구자들이 이를 깊은 네트워크에 포함시키도록 동기를 부여했습니다. 적대적 도메인 적응 접근 방식은 도메인 간의 분포 불일치를 최소화하여 전이 가능하고 도메인 불변적인 특징을 얻는 경향이 있습니다. 적대적 도메인 적응의 주요 아이디어는 생성적 적대 네트워크(Generative Adversarial Nets, GAN) [61]에서 영감을 받았으며, 이는 적대적 목적(adversarial objective)을 통해 교차 도메인 불일치를 최소화하는 경향이 있습니다. GAN은 **생성자 모델 G(generator model G)**와 **판별자 모델 D(discriminator model D)**라는 두 플레이어 게임으로 구성된 딥러닝 기반 생성 모델입니다. 생성자는 소스 데이터로부터 관심 도메인과 유사한 샘플을 생성하고, 판별자를 혼란시켜 잘못된 결정을 내리도록 하는 것을 목표로 합니다. 그런 다음 판별자는 관심 도메인의 실제 데이터와 모델 G가 생성한 위조품을 구별하려는 경향이 있습니다.

Ganin et al. [35]은 모델에 효과적인 **그레디언트 역전 계층(Gradient Reversal Layer, GRL)**을 추가하여 도메인 갭을 일치시키는 깊은 적대적 기반 도메인 적응 접근 방식을 제안했습니다. 순방향 전파(forward propagation) 동안 GRL은 입력을 변경하지 않는 항등 함수처럼 작동합니다. 그러나 역전파(backpropagation) 단계에서는 기울기(gradient)에 음의 스칼라를 곱하여 역전시킵니다. 제안된 모델은 방대한 양의 소스 레이블된 데이터와 많은 양의 레이블 없는 타겟 데이터에 대해 훈련될 수 있습니다. 이 모델은 일반적으로 세 부분으로 분해됩니다: 특징 추출기 G_f (feature extractor G_f), 레이블 예측기 G_y (label predictor G_y), 그리고 **도메인 분류기 G_d (domain classifier G_d)**입니다. G_f는 레이블 예측기와 도메인 분류기 모두를 위한 특징을 생성합니다. GRL은 G_f와 G_d 사이에 삽입됩니다. 모델의 세 부분은 소스 레이블된 데이터와 레이블 없는 타겟 데이터를 기반으로 해당 매개변수 
theta_f, 
theta_y, 
theta_d를 학습할 수 있습니다. 학습 단계에서 모델은 레이블 예측기 손실을 최소화하여 매개변수 
theta_f와 
theta_y를 학습합니다. 이 과정은 특징 추출기가 소스 도메인에서 좋은 레이블 예측을 위해 식별 가능한 특징을 생성하도록 강제합니다. 동시에 모델은 도메인 불변 특징을 얻기 위해 도메인 분류기 손실을 각각 최대화하고 최소화하여 매개변수 
theta_f와 
theta_d를 학습합니다.

Pei et al. [62]은 단일 도메인 판별자를 사용하는 것이 주변 분포만 일치시키고 클래스 조건부 분포 간의 불일치를 무시하여 부정적 전이와 도메인 간의 클래스 오정렬을 유발한다고 주장했습니다. 다중 적대적 도메인 적응(Multi-Adversarial Domain Adaptation, MADA) [62]은 도메인 간의 결합 분포의 변화를 줄이고 여러 클래스별 도메인 판별자를 구성함으로써 다른 클래스 분포의 세분화된 정렬을 가능하게 하기 위해 제안되었습니다. 각 판별자는 동일한 클래스에 속하는 소스 및 타겟 데이터 샘플만 일치시킵니다.

생성자 G와 판별자 D는 도메인 혼란을 위한 적대적 목적의 미니맥스(minimax) 최적화를 통해서도 구현될 수 있습니다. 이 접근 방식은 도메인 적응 이론 [64], [65]에서 영감을 받았으며, 도메인 간의 전이 가능한 표현은 식별 정보를 포함하지 않으므로, 알고리즘이 이 표현을 기반으로 입력 샘플의 원점을 학습할 수 없음을 시사합니다. 즉, 미니맥스 최적화 프로세스는 도메인 간의 깊은 불변 표현을 학습하여 도메인 불일치를 일치시키는 것을 목표로 합니다. [63]과 [36]은 딥 신경망에서 미니맥스 최적화 기반 적대적 도메인 적응을 처음으로 구축했습니다.

Tzeng et al. [63]은 분류 손실, 소프트 레이블 손실, 도메인 분류기 손실, 도메인 혼란 손실을 최소화하여 도메인 간의 주변 및 조건부 분포를 모두 조정하는 **적대적 CNN 기반 아키텍처(adversarial CNN-based architecture)**를 소개했습니다. 이 모델은 먼저 각 범주에서 소스 레이블된 데이터에 대한 평균 확률 분포(소프트 레이블)를 계산합니다. 이는 나중에 타겟 레이블된 데이터에 대해 미세 조정되어 도메인 간의 클래스 조건부 분포를 소프트 레이블과 일치시킬 수 있습니다. 하드 레이블과 달리 소프트 레이블은 각 샘플의 범주에 대한 더 전이 가능하고 유용한 정보와 범주 간의 관계를 제공합니다. 예를 들어, 책장은 자전거보다 파일 캐비닛과 더 유사합니다. 도메인 혼란 손실은 도메인 레이블에 대한 균일 분포와 예측된 도메인 레이블 출력 간의 교차 엔트로피입니다. 이 손실을 최소화하면 알고리즘이 판별자를 최대한 혼란시키는 도메인 불변 표현을 추출하도록 강제합니다.

시각 적대적 도메인 적응(Visual adversarial domain adaptation) 또한 생성적 적대 네트워크(GAN)를 활용하여 도메인 간의 변화를 줄입니다. 생성적 적대적 도메인 적응에서 생성자 모델 G는 그럴듯하지 않은 이미지를 합성하는 것을 목표로 하는 반면, 판별자 모델 D는 합성된 샘플과 실제 샘플을 구별하려고 합니다. 생성적 적대 네트워크를 사용하는 시각 도메인 적응 기술은 픽셀 수준(pixel-level), 특징 수준(feature-level) 또는 둘 다에서 표현을 채택합니다.

픽셀 수준 접근 방식은 원시 픽셀 공간에서 적응을 수행하여 한 도메인의 이미지를 다른 도메인의 스타일 이미지로 직접 변환합니다. Bousmal et al. [69]은 생성적 적대 네트워크를 활용하여 한 도메인을 다른 도메인에 적응시키는 비지도 픽셀 수준 도메인 적응 방법인 **픽셀DA(PixelDA)**를 제안했습니다. 이 모델은 소스 도메인 이미지가 원래 내용을 보존하면서 타겟 도메인 분포에서 그려진 것처럼 보이도록 변경합니다. 시뮬레이션+비지도 학습(Simulated+Unsupervised learning, SimGAN) [70]은 실제적이고 관심 도메인의 이미지와 유사한 합성 이미지를 생성하는 것을 목표로 합니다. 시뮬레이터는 먼저 노이즈 벡터에서 합성 이미지를 생성합니다. 그런 다음 리파이너 네트워크(refiner network)는 적대적 손실을 최적화하여 타겟 이미지와 유사하도록 이들을 개선합니다.

픽셀 수준 접근 방식과 대조적으로, 특징 수준 방법은 도메인 간의 불일치를 완화하기 위해 식별 특징 공간에서 표현을 수정합니다. 도메인 전이 네트워크(Domain Transfer Network, DAN) [72]는 임베딩 공간에서 일관성을 강제하여 소스 이미지를 타겟 이미지로 변환하는 특징 수준 생성 기반 적응입니다. Hoffman et al. [66]은 **사이클 일관 적대적 도메인 적응(Cycle-Consistent Adversarial Domain Adaptation, CyCADA)**을 제안했습니다. 이는 픽셀 수준 [68], [69], [70]과 특징 수준 [33], [67] 적대적 도메인 적응 방법을 사이클 일관 이미지-대-이미지 변환(cycle-consistent image-to-image translation) 기술 [71]과 융합하여 한 도메인에서 다른 도메인으로의 매핑을 지시합니다. 이 모델은 픽셀 수준, 특징 수준, 의미론적(semantic), 그리고 두 도메인 모두에서 사이클 일관성 손실을 포함한 여러 손실을 최소화하여 픽셀 수준과 특징 수준 모두에서 표현을 동시에 채택합니다.
