# domain_adaptation

## 기존 문제
데이터 분포의 불일치인공지능 모델은 특정 데이터로 학습될 때 그 데이터의 특징과 분포를 학습합니다. 문제는 실제 환경에서는 모델이 학습하지 않은, 분포가 다른 다양한 데이터와 마주칠 수 있다는 점입니다. 예를 들어, 실내 사진으로만 학습된 모델이 갑자기 야외 사진을 보면 잘 인식하지 못할 수 있습니다.
-> 이렇게 학습 데이터와 실제 적용할 데이터 간에 분포 차이가 발생하면, 모델의 성능이 크게 떨어집니다. 모델이 학습한 "세상"과 실제 "세상"이 다르기 때문이죠.

새로운 데이터 수집 및 레이블링의 어려움: 새로운 도메인 데이터가 나타날 때마다 처음부터 다시 데이터를 수집하고, 시간과 비용을 들여 수작업으로 레이블(정답)을 다는 것은 매우 비효율적입니다. 특히 레이블링은 전문가의 지식을 필요로 하는 경우가 많아 더욱 어렵습니다.

## domain_adaptation이란?
도메인 적응은 특정 데이터셋(소스 도메인)으로 학습시킨 인공지능 모델이, 분포가 다른 새로운 데이터셋(타겟 도메인)에서도 성능 저하 없이 잘 작동하도록 모델을 조정하는 기술
## domain_adaptation의 특징
도메인 적응의 작동 원리와 구조는 다양한 방식이 있지만, 핵심은 두 도메인(소스와 타겟) 간의 차이를 줄이는 것입니다.

주로 다음과 같은 방식으로 작동하며, 일반적인 구조는 특징 추출기와 분류기로 구성됩니다.

특징 추출기(Feature Extractor): 소스 도메인과 타겟 도메인의 데이터를 입력받아 의미 있는 특징(feature)을 추출하는 부분입니다.

분류기(Classifier): 특징 추출기가 뽑아낸 특징을 바탕으로 최종 예측(예: 이미지 분류)을 수행하는 부분입니다.

작동 방식 예시:

특징 기반 적응 (Feature-based Adaptation):

작동: 가장 흔한 방식 중 하나로, 소스 도메인과 타겟 도메인의 데이터가 모두 같은 **잠재 공간(latent space)**에 놓이도록 특징 추출기를 학습시킵니다. 즉, 두 도메인의 데이터가 서로 구별되지 않는 "도메인 불변(domain-invariant)" 특징을 뽑아내도록 만드는 것이 목표입니다.

구조: 특징 추출기에서 소스 데이터와 타겟 데이터의 특징 분포를 유사하게 만들도록 학습하고, 이후 분류기는 이 특징들을 바탕으로 예측을 수행합니다. 이때 도메인 분류기(Domain Classifier)를 추가하여 특징 추출기가 도메인을 구분하지 못하도록 적대적으로 학습시키는 방식(GAN 기반)이 많이 사용됩니다.

모델 기반 적응 (Model-based Adaptation):

작동: 소스 도메인에서 학습된 모델의 파라미터(가중치)를 타겟 도메인에 맞게 미세 조정(fine-tuning)하는 방식입니다. 타겟 도메인 데이터가 적을 때 효과적일 수 있습니다.

인스턴스 기반 적응 (Instance-based Adaptation):

작동: 소스 도메인의 데이터 중 타겟 도메인과 유사한 데이터에 더 큰 가중치를 부여하거나, 아예 유사하지 않은 데이터를 제거하여 학습합니다.

## domain_adaptation이 문제를 해결하는 방법
데이터 분포 정렬: 소스 도메인과 타겟 도메인의 데이터 분포를 최대한 가깝게 만듭니다. 이를 통해 모델이 특정 도메인의 특성에만 과도하게 의존하지 않고, 두 도메인 모두에서 공통적으로 유효한 특징을 학습하게 됩니다.

전이 학습(Transfer Learning)의 효율성 증대: 기존에 대량의 소스 데이터로 학습된 강력한 모델의 지식을 버리지 않고, 타겟 도메인에 효율적으로 '전이'하여 활용할 수 있게 합니다. 이는 새로운 데이터셋을 처음부터 학습하는 것보다 훨씬 효율적입니다.

레이블링 비용 절감: 특히 비지도(unsupervised) 또는 준지도(semi-supervised) 도메인 적응 방법은 타겟 도메인의 레이블이 없거나 매우 적더라도 적응을 가능하게 하여, 데이터 레이블링에 드는 막대한 비용과 시간을 절약해 줍니다.
## 사용되는 곳
자율주행: 시뮬레이션 환경에서 학습된 자율주행 모델을 실제 도로 환경에 적용할 때 발생할 수 있는 데이터 분포 차이(날씨, 조명, 지형 등)를 극복하는 데 사용됩니다.

의료 영상 진단: 특정 병원의 장비로 촬영된 의료 영상으로 학습된 AI 모델을 다른 병원의 장비(해상도, 노이즈 등이 다름)로 촬영된 영상에 적용하여 진단 정확도를 유지하는 데 활용됩니다.

자연어 처리 (NLP): 특정 도메인(예: 뉴스 기사)으로 학습된 언어 모델을 다른 도메인(예: 법률 문서, 의료 기록)의 텍스트에 적용하여 성능을 높이는 데 쓰입니다.

로봇 공학: 가상 환경에서 학습된 로봇 제어 정책을 실제 로봇에 적용할 때, 시뮬레이션-실제 간의 간극(Sim-to-Real gap)을 줄이는 데 필수적입니다.

얼굴 인식 및 생체 인식: 다양한 환경(조명, 각도, 인종 등)에서 촬영된 얼굴 이미지에 모델이 강건하게 작동하도록 돕습니다.

산업 현장 검사: 공장의 특정 생산 라인에서 수집된 불량품 이미지로 학습된 모델을, 미세하게 다른 조건의 다른 라인에 적용할 때 유용합니다.

## domain_adaptation의 종류,종류별 특징, 접근법. 장단점점
### 지도 도메인 적응 (Supervised Domain Adaptation, SDA)
설명: 소스 도메인의 데이터는 물론, 타겟 도메인의 데이터에도 충분한 양의 레이블이 있는 경우입니다.

목표: 소스 도메인에서 학습한 모델을 타겟 도메인의 레이블된 데이터를 사용하여 미세 조정(fine-tuning)함으로써 두 도메인 간의 차이를 줄이고 타겟 도메인 성능을 극대화합니다.

특징: 가장 직접적인 방식이며, 타겟 도메인에 레이블된 데이터가 많을수록 성능이 좋습니다. 하지만 타겟 도메인의 레이블링 비용이 많이 든다는 단점이 있습니다. 사실상 "두 번째 지도 학습"에 가깝지만, 소스 모델의 사전 학습 지식을 활용한다는 점에서 순수 지도 학습과는 다릅니다.

###  준지도 도메인 적응 (Semi-Supervised Domain Adaptation, SSDA)
설명: 소스 도메인의 데이터는 레이블이 있지만, 타겟 도메인에는 소수의 레이블된 데이터와 대량의 레이블 없는 데이터가 함께 있는 경우입니다.

목표: 소수의 레이블된 타겟 데이터를 최대한 활용하면서, 대량의 레이블 없는 타겟 데이터로부터 유용한 정보를 추출하여 모델을 적응시킵니다.

특징: 실제 환경에서 가장 흔히 마주하는 시나리오 중 하나입니다. 레이블링 비용과 적응 성능 사이에서 균형을 잡는 방식입니다. 보통 자기 학습(self-training)이나 일관성 정규화(consistency regularization)와 같은 기법들을 활용하여 레이블 없는 데이터를 활용합니다.

###  비지도 도메인 적응 (Unsupervised Domain Adaptation, UDA)
설명: 소스 도메인의 데이터는 레이블이 있지만, 타겟 도메인의 데이터는 모두 레이블이 없는 경우입니다.

목표: 타겟 도메인에 대한 어떠한 레이블 정보 없이, 소스 도메인에서 학습한 모델을 타겟 도메인에 성공적으로 전이시키는 것입니다.

특징: 가장 어려운 시나리오이지만, 레이블링 비용이 전혀 들지 않아 가장 실용적입니다. 다양한 고급 기술들이 이 분야에서 연구됩니다.

특징 정렬 (Feature Alignment): 두 도메인에서 추출된 특징 분포를 유사하게 만듭니다. (예: MMD(Maximum Mean Discrepancy), GAN 기반 적대적 학습 - DANN 등)

자기 지도 학습 (Self-Supervised Learning): 타겟 도메인 데이터 자체로부터 유용한 신호를 학습합니다. (예: SHOT과 같이 의사 레이블(pseudo-label)을 생성하여 학습하거나, 회전 예측과 같은 보조 과제를 통해 특징을 학습)
