# domain_adaptation

## 기존 문제
데이터 분포의 불일치인공지능 모델은 특정 데이터로 학습될 때 그 데이터의 특징과 분포를 학습합니다. 문제는 실제 환경에서는 모델이 학습하지 않은, 분포가 다른 다양한 데이터와 마주칠 수 있다는 점입니다. 예를 들어, 실내 사진으로만 학습된 모델이 갑자기 야외 사진을 보면 잘 인식하지 못할 수 있습니다.
-> 이렇게 학습 데이터와 실제 적용할 데이터 간에 분포 차이가 발생하면, 모델의 성능이 크게 떨어집니다. 모델이 학습한 "세상"과 실제 "세상"이 다르기 때문이죠.

새로운 데이터 수집 및 레이블링의 어려움: 새로운 도메인 데이터가 나타날 때마다 처음부터 다시 데이터를 수집하고, 시간과 비용을 들여 수작업으로 레이블(정답)을 다는 것은 매우 비효율적입니다. 특히 레이블링은 전문가의 지식을 필요로 하는 경우가 많아 더욱 어렵습니다.
